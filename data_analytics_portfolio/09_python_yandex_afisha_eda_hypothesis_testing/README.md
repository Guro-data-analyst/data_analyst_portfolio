# Исследовательский анализ данных Яндекс Афиши и проверка гипотез

## Описание проекта

Учебный Python-проект по анализу данных сервиса Яндекс Афиша за период с июня по октябрь 2024 года. На предыдущем этапе был разработан BI-дашборд, который показал рост количества заказов осенью при изменении средней выручки с заказа. В этом проекте проводится более глубокий исследовательский анализ и статистическая проверка гипотез.

## Бизнес-задача

Выявить, как менялись заказы, выручка, структура мероприятий и поведение пользователей по сезонам, регионам, партнёрам и типам устройств, а также проверить статистические гипотезы о различиях между мобильными и стационарными пользователями.

## Что было сделано

- Загружены и изучены данные по заказам, мероприятиям и валютным курсам.
- Проведена предобработка: преобразование дат, проверка пропусков, дубликатов, отрицательной выручки и категориальных признаков.
- Подготовлены дополнительные признаки для анализа: месяц, сезон, день недели, тип устройства и метрики заказов.
- Проанализирована динамика заказов по месяцам.
- Сравнены летний и осенний периоды.
- Проанализирована структура заказов по типам мероприятий.
- Исследована активность пользователей по дням недели.
- Выделены ключевые регионы и партнёры по выручке и количеству мероприятий.
- Проведена статистическая проверка гипотез по пользователям мобильных и стационарных устройств.
- Сформулированы выводы и рекомендации для продукта и маркетинга.

## Ключевые выводы

- Количество заказов за период выросло с **34 242** в июне до **99 182** в октябре.
- Среднемесячное количество заказов осенью выросло примерно на **112%** относительно летнего периода.
- Доля стендапа выросла на **5,87 п.п.**, что делает его одним из драйверов сезонного роста.
- Концерты остаются важным направлением, но их доля снизилась на **5,35 п.п.**
- Каменевский регион формирует около **37,5%** всей выручки.
- Топ-5 партнёров обеспечивают около **65,8%** выручки.
- После статистической проверки различия между мобильными и стационарными пользователями оказались значимыми.

## Статистические гипотезы

Проверялись гипотезы о различиях между пользователями мобильных и стационарных устройств:

1. Мобильные пользователи делают больше заказов.
2. У мобильных пользователей отличается интервал между заказами.

Для проверки использовался непараметрический подход, так как распределения не соответствовали нормальному виду. В проекте отдельно учитывалась проблема пересекающихся пользователей, которые могли делать заказы с разных типов устройств.

# Предобработка и категоризация данных о видеоиграх

## Описание проекта

Учебный Python-проект по подготовке данных о видеоиграх для дальнейшего анализа. Задача — познакомиться с датасетом, проверить корректность данных, провести предобработку, отобрать игры за период 2000–2013 гг., категоризировать оценки пользователей и критиков, а также выделить топ платформ по количеству выпущенных игр.

## Бизнес-контекст

Данные готовятся для аналитической статьи о рынке видеоигр начала XXI века. Перед анализом продаж, жанров и платформ необходимо привести датасет к корректному виду: исправить типы данных, обработать пропуски, удалить дубликаты и добавить аналитические категории.

## Данные

В проекте использовался учебный датасет Яндекс Практикума `new_games.csv` со сведениями о видеоиграх:

- название игры;
- платформа;
- год выпуска;
- жанр;
- продажи в Северной Америке, Европе, Японии и других регионах;
- оценка критиков;
- оценка пользователей;
- рейтинг ESRB.

Датасет не включён в репозиторий, так как относится к учебной платформе. В ноутбуке сохранены код, промежуточные результаты и выводы.

## Инструменты

- Python
- pandas
- Jupyter Notebook

## Что было сделано

- Загружен и изучен датасет из 16 956 строк и 11 столбцов.
- Названия столбцов приведены к `snake_case`.
- Исправлены типы данных в столбцах с продажами, пользовательскими оценками и годом выпуска.
- Проанализированы пропуски в данных в абсолютных и относительных значениях.
- Обработаны пропуски в оценках, рейтинге, годе выпуска и ключевых категориальных полях.
- Нормализованы текстовые значения и проверены дубликаты.
- Отобраны игры за период 2000–2013 гг.
- Добавлены категории пользовательских и экспертных оценок: низкая, средняя, высокая, нет оценки.
- Выделены топ-7 платформ по количеству выпущенных игр за выбранный период.

## Ключевые результаты

- После предобработки сохранено 16 500 строк из 16 956.
- Для анализа выбран период 2000–2013 гг.; итоговый срез содержит 12 829 игр.
- Топ-7 платформ по количеству игр: **PS2**, **DS**, **Wii**, **PSP**, **X360**, **PS3**, **GBA**.
- Топ-7 платформ охватывают **9 749** игр, или **76,0%** выбранного периода.
- В данных много пропусков в пользовательских и экспертных оценках, поэтому для дальнейшего анализа добавлена отдельная категория `нет оценки`.

## Новые поля

- `user_score_category` — категория пользовательской оценки:
  - высокая оценка;
  - средняя оценка;
  - низкая оценка;
  - нет оценки.
- `critic_score_category` — категория оценки критиков:
  - высокая оценка;
  - средняя оценка;
  - низкая оценка;
  - нет оценки.

## Вывод

Проект демонстрирует базовый цикл подготовки данных: загрузку, первичное изучение, очистку, обработку пропусков, преобразование типов, фильтрацию, категоризацию и подготовку аналитического среза для дальнейшего анализа.

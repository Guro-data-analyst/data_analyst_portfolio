# Data Analytics Portfolio — Кирилл Гуро

Портфолио учебных проектов по аналитике данных. Проекты оформлены в формате GitHub-кейсов: бизнес-задача, инструменты, SQL/Python-код, ключевые выводы и рекомендации.

## О себе

Начинающий аналитик данных с бизнес-бэкграундом в ритейле, закупках, товарных остатках и контроле качества. Владею SQL, PostgreSQL, Python/pandas, Excel, Google Таблицами и DataLens. Интересуюсь аналитикой данных в ритейле, e-commerce, продукте и операционных процессах.

## Навыки

- SQL, PostgreSQL
- CTE, JOIN, агрегирующие функции, оконные функции
- Анализ данных и ad hoc-задачи
- Очистка данных от выбросов
- Расчёт долей, средних, медиан, перцентилей
- Сегментация данных
- Интерпретация результатов и подготовка бизнес-рекомендаций

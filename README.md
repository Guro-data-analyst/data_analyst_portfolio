# Портфолио аналитика данных — Кирилл Гуро

Портфолио учебных проектов по аналитике данных. В проектах представлены SQL-анализ, ad hoc-задачи, Python/pandas, продуктовая аналитика, A/B-тестирование, проверка гипотез, визуализация в Yandex DataLens и подготовка бизнес-выводов.

## Проекты

| № | Проект | Задача | Инструменты |
|---|---|---|---|
| 01 | [SQL-анализ поведения игроков и внутриигровых покупок](01_sql_fantasy_game_analysis/) | Проанализировать платящих игроков, покупки, аномалии и популярность предметов | SQL, PostgreSQL |
| 02 | [SQL-анализ рынка недвижимости](02_sql_real_estate_ad_hoc_analysis/) | Решить ad hoc-задачи для агентства недвижимости: активность объявлений, сезонность, сравнение регионов | SQL, PostgreSQL |
| 03 | [A/B-тестирование алгоритма рекомендаций](03_ab_test_recommendation_algorithm/) | Рассчитать параметры A/B-теста, проверить корректность эксперимента и оценить результат нового алгоритма | Python, pandas, statsmodels, matplotlib |
| 04 | [Предобработка и категоризация данных о видеоиграх](04_python_game_data_preprocessing/) | Очистить датасет, обработать пропуски, отфильтровать период 2000–2013 гг., категоризировать оценки и выделить топ платформ | Python, pandas |
| 05 | [DataLens-дашборд TED-конференций](05_datalens_ted_conferences_dashboard/) | Визуализировать опыт проведённых TED-конференций: темы, спикеров, просмотры, реакцию аудитории и детали выступлений | Yandex DataLens, SQL |
| 06 | [DataLens: бизнес-метрики сервиса доставки еды](06_datalens_food_delivery_metrics/) | Оценить DAU, CR, Retention, средний чек, LTV и подготовить рекомендации для роста сервиса доставки | Yandex DataLens, SQL, PostgreSQL |
| 07 | [DataLens: аналитика мероприятий Яндекс Афиши](07_datalens_yandex_afisha_events_dashboard/) | Проанализировать выручку, заказы, средний чек, регионы, устройства, типы мероприятий и популярные события | Yandex DataLens, BI, KPI |
| 08 | [DataLens: аналитика рынка недвижимости](08_datalens_real_estate_dashboard/) | Создать дашборд для анализа цен, объектов, городов, динамики и характеристик недвижимости | Yandex DataLens, BI, расчётные поля |
| 09 | [Python: исследовательский анализ Яндекс Афиши и проверка гипотез](09_python_yandex_afisha_eda_hypothesis_testing/) | Провести EDA, сравнить сезонные изменения, изучить регионы/партнёров и проверить гипотезы по типам устройств | Python, pandas, scipy, plotly |

## Навыки

SQL, PostgreSQL, Python, pandas, numpy, matplotlib, seaborn, plotly, scipy, statsmodels, Yandex DataLens, предобработка данных, категоризация, исследовательский анализ данных, A/B-тестирование, проверка гипотез, расчёт MDE и размера выборки, анализ продуктовых метрик, DAU, CR, Retention, LTV, визуализация данных, построение дашбордов, BI-аналитика, подготовка выводов и рекомендаций.

## Примечание

В DataLens-проектах используются обезличенные экспорт-файлы: параметры подключений удалены или замаскированы перед публикацией на GitHub. Исходные датасеты учебных Python-проектов не опубликованы из-за условий использования данных.

# Данные

Исходные датасеты не включены в репозиторий, так как использовались учебные данные Яндекс Практикума.

В проекте используются файлы:

- `final_tickets_orders_df.csv` — заказы билетов;
- `final_tickets_events_df.csv` — справочник мероприятий;
- `final_tickets_tenge_df.csv` — курсы валют/данные для пересчёта.

В ноутбуке сохранена структура анализа, код, визуализации и выводы.

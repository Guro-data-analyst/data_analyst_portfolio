# A/B-тестирование алгоритма рекомендаций в развлекательном приложении

## Цель проекта

Подготовить и проанализировать A/B-тест нового алгоритма рекомендаций для развлекательного приложения с бесконечной лентой. Новый алгоритм должен был повысить вовлечённость пользователей за счёт более релевантного контента.

## Бизнес-контекст

В приложении есть две модели монетизации: платная подписка без рекламы и показ рекламы пользователям без подписки. Команда рекомендаций предложила новый алгоритм, а задача аналитика — рассчитать параметры теста, проверить корректность эксперимента и оценить, стоит ли внедрять изменение.

## Данные

В проекте использовались учебные датасеты Яндекс Практикума:

- `sessions_project_history.csv` — исторические данные по сессиям пользователей;
- `sessions_project_test_part.csv` — данные первого дня A/B-теста;
- `sessions_project_test.csv` — данные всего периода A/B-теста.

Данные не включены в репозиторий, так как относятся к учебной платформе. В ноутбуке сохранены код, расчёты, визуализации и итоговые выводы.

## Что было сделано

- Провёл исследовательский анализ исторических данных.
- Рассчитал долю успешных первых сессий, где пользователь просмотрел 4 и более страниц.
- Определил целевую метрику A/B-теста.
- Рассчитал MDE, необходимый размер выборки и длительность эксперимента.
- Проверил корректность сплитования пользователей по группам A и B.
- Проверил, что пользователи не попали одновременно в обе группы.
- Сравнил группы по устройствам и регионам.
- Рассчитал фактическую разницу между группами по ключевой метрике.
- Провёл статистическую проверку гипотезы о росте метрики в группе B.
- Подготовил выводы и рекомендации для продуктовой команды.

## Ключевые результаты

- Базовый уровень целевой метрики по историческим данным: **31,06%**.
- Запланированный MDE: **3% относительного изменения**, или около **0,93 п.п.**.
- Необходимый размер выборки: **39 034 пользователя на группу**.
- Фактический размер выборки: **15 162 пользователя в группе A** и **15 416 пользователей в группе B**.
- Доля успешных первых сессий:
  - группа A: **31,57%**;
  - группа B: **31,47%**.
- Абсолютная разница: **-0,11 п.п.**.
- Относительное изменение: **-0,33%**.
- P-value для проверки гипотезы `B > A`: **0,578352**.

## Вывод

Новый алгоритм рекомендаций не показал статистически значимого улучшения ключевой метрики. Фактическое изменение оказалось отрицательным и существенно ниже запланированного MDE. В текущем виде новый алгоритм не рекомендуется к внедрению.

## Рекомендации

- Продолжить использовать текущий алгоритм рекомендаций.
- Проанализировать причины снижения метрики в группе B.
- Доработать новый алгоритм и провести повторный тест.
- Увеличить длительность эксперимента, чтобы достичь необходимого размера выборки.
- Дополнительно проверить влияние алгоритма на удержание, глубину просмотра и конверсию в подписку.
